# AirType 跨屏输入

手机打字 / 语音 → 文字直接出现在电脑光标处;
手机拍照 → 自动粘贴进电脑当前输入框。
纯局域网通信:手机侧零安装(浏览器即用),电脑侧零第三方依赖。

## 快速开始

### Windows

1. 双击 `build/AirType.exe`(需系统自带 .NET Framework 4.x,Win10/11 均满足);
2. 自动弹出"扫码连接"窗口,右下角托盘常驻;
3. 手机(与电脑同一 WiFi)用微信"扫一扫"或系统相机扫码,或在手机浏览器输入窗口上的地址;
4. 手机页面出现绿点"已连接"即可开打。

托盘右键菜单:首行常驻显示当前地址 / 端口 / 连接状态;打开扫码连接页面 / 重新生成配对码 / 暂停注入 / 选择网卡(扫码地址) / 开机启动开关 / 查看日志 / 打开接收文件夹 / 最近接收 / 退出。双击托盘图标可再次打开扫码页。

### 麒麟(Kylin V10 等 Linux 桌面)

```bash
bash kylin/install.sh        # 一键安装:补依赖、建桌面图标、装开机自启,全程零输入
python3 kylin/airtype.py     # 或直接运行,浏览器打开 http://localhost:8765/pair
```

首次可先 `python3 kylin/airtype.py --selfcheck` 检查注入通道;多网卡连不上时,启动日志会列出候选地址,用 `--ip <地址>` 指定网卡重启即可。

## 手机页面

**两种输入模式**

| 模式 | 行为 | 适合 |
|---|---|---|
| 手动发送 | 打完 / 说完点「发送」 | 短消息 |
| 实时同步 | 边说边上屏:整句立即发送,连续输入至少每 0.4 秒同步一次 | 长段口述 |

辅助:回车 / 退格 / 撤回(删上次发送)/ 清空;可开「自动清空」(停顿 2.5 秒自动清,默认关)。

**图片 → 电脑(两版都有)**

点「图片→电脑」多选相册或现场拍照:

- **智能压缩**:超过 2MB 或长边超过 2048px 自动转 JPEG;「原图」开关切回不压缩(状态会被记住);
- **传输**:显示"发送 i/N · 文件名(百分比)"进度,上传中再点一次 = 取消整批,失败自动重试一次;
- 保存到 `下载/AirType接收`(重名自动加序号,单文件上限 200MB);
- Windows 自动粘贴到当前光标所在应用(微信 / Word / 记事本等),剪贴板同时提供文件与位图两种格式;粘贴是异步的,手机先显示"已保存",稍后追送真实结果;粘贴失败、目标非图片、或开了暂停注入时自动降级为只保存,文件不丢;
- 电脑取用:托盘「打开接收文件夹」「最近接收」,或扫码页「打开接收文件夹」按钮。

> 麒麟的自动粘贴依赖 xclip / wl-copy 及目标应用支持,属尽力而为;落盘保存始终可用。

## 功能一览

- **文字输入**:中文 / emoji 经手机输入法直达电脑光标,支持手动 / 实时两种模式;
- **配对**:4 位数字配对码,每次启动随机更换,可扫码或手输;
- **电脑端控制**(扫码页,仅本机可操作):断开当前手机、重新配对(换码并吊销旧会话)、打开接收文件夹;
- **状态反馈**:手机绿点"已连接";电脑扫码页与托盘首行实时显示地址:端口与连接状态;配对码变更后两端都会引导重新配对;
- **多网卡排查**:二维码固定指向"当前扫码地址",Windows 托盘可随时切换网卡(免重启),麒麟用 `--ip`;
- **单会话**:同一时间仅一台手机,新连接顶掉旧连接并说明原因;
- **暂停注入 / 开机自启(两版)/ 日志**(Windows `%LocalAppData%\AirType\log.txt`,麒麟 `~/.config/airtype/log.txt`)。

## 工作原理

```
手机浏览器(mobile.html)                电脑
  │ 文字/按键 → JSON 文本帧              ├─ Windows: AirType.exe(SendInput 注入)
  ├─────────── WebSocket :8765 ─────────┤
  │ 图片 → 二进制分块(file 协议)         └─ 麒麟: airtype.py(xdotool/dotool/剪贴板)
```

- **零依赖**:Windows 版为单个 C# 5 源文件,用系统 `csc.exe` 编译,网页与图标内嵌进 exe;麒麟版仅用 Python 3 标准库;WebSocket 为手写 RFC6455(含分片重组,兼容微信浏览器)。
- **注入**:Windows 用 `SendInput` 逐字符注入,不占剪贴板;麒麟按会话自动选通道(X11:剪贴板 > xdotool > dotool;Wayland:dotool > 剪贴板 > xdotool),失败原因回传手机。
- **撤回护栏**:电脑记账"本会话在当前前台窗口实际注入的字符数"(切窗口自动归零),批量退格超配额会被截断,防止误删其他应用文字。
- **安全**:数据不出局域网、不经任何服务器;4 位码防误连;文件名消毒、只写接收目录;帧 / 文件大小设上限;扫码页与二维码资源仅限本机访问(其他设备返回 403)。

## 从源码构建

**Windows**:运行 `build\build_stage1.bat`(系统 `csc.exe`,.NET Framework 4.x),产物 `build\AirType.exe`。三条硬约束:① 仅 C# 5 语法(连字符串插值都不行);② 源文件须保持 UTF-8 with BOM,否则中文乱码;③ `src/web/` 页面与 `src/airtype.ico` 是内嵌资源,改后须重新编译,且编译前先退出运行中的实例(文件占用)。

**麒麟**:免编译,`python3 kylin/airtype.py` 直接运行;页面在 `kylin/web/`,改完刷新浏览器。

## 目录结构

```
src/     Windows 版:AirType.cs(单文件)+ airtype.ico + web/(手机端 / 扫码页资源)

```

## 常见问题

**手机扫码后连不上 / 超时?**
1. 手机是否连了与电脑**同一个 WiFi**(移动数据必连不上);
2. 多网卡(VPN / 热点 / 虚拟网卡)时二维码可能指向手机访不到的网卡:看扫码页当前地址换一个试试(Windows 托盘「选择网卡」直接切,麒麟 `--ip` 后重启);
3. Windows 防火墙拦了入站,管理员 PowerShell 放行:
   ```powershell
   New-NetFirewallRule -Name AirType8765 -DisplayName "AirType 局域网输入 (TCP 8765)" -Direction Inbound -Protocol TCP -LocalPort 8765 -Action Allow -Profile Any
   ```
   注意 **Block 规则优先于 Allow**:若曾在放行弹窗点"取消",系统会生成拦截规则,须删掉它放行才生效;
4. 仍不行:把电脑的网络配置文件从"公用"改为"专用"。

**配对码变了,手机连不上?** 每次启动换新码,旧码 / 旧页面立即失效;手机页面会弹输码框,直接输入电脑屏幕上的新 4 位码即可,不用重扫。

**图片传过去了但没粘贴?** 粘贴只发生在"传输完成那一刻"的前台窗口,发图后别急着切窗口;目标不认剪贴板文件引用或开了暂停注入时会自动降级为只保存,去 `下载/AirType接收` 取。

**手机显示"注入失败"?** 电脑端注入通道异常(麒麟常见:权限、会话切换),看电脑日志;麒麟跑 `--selfcheck` 复查,必要时 `--test-inject` 实测。

**多台手机能同时用吗?** 不能,同一时间仅一个会话,新设备会顶掉旧设备。

## 已知边界

- 只做"往电脑输入",不做反向(电脑 → 手机)与剪贴板同步;
- 实时同步用最长公共前缀增量算法,手机大段乱序编辑后以手机内容为准;
- 终端类窗口剪贴板粘贴是 Ctrl+Shift+V,麒麟剪贴板通道对此不敏感(键入通道无此问题);
- Windows 扫码弹窗用系统 WebBrowser 控件(IE11 内核),页面代码须保持 ES5。
